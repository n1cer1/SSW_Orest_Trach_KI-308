# SSW_Orest_Trach_KI-308
Курсова робота з предмету "Системне програмне забезпечення"

Тема: Розробка програмного забезпечення для роботи з файловою системою.
Розробка програми, що дозволяє працювати з файловою системою операційної системи.
1. Перегляд файлової структури (File Explorer):
Відображення структури дисків, папок та файлів у вигляді дерева для зручної навігації по файловій системі.

2. Пошук файлів:
Можливість швидко знаходити файли за назвою, розширенням або частиною назви у вибраній папці або на всьому диску.

3. Операції з файлами:
Підтримка основних операцій з файлами та папками: створення, копіювання, переміщення, перейменування та видалення.

4. Інформація про файл:
Відображення детальної інформації про файл або папку (розмір, тип, дата створення, дата зміни, шлях до файлу).

5. Сортування та фільтрація:
Можливість сортувати файли за назвою, розміром, типом або датою створення.

6. Попередній перегляд файлів:
Функція перегляду вмісту текстових файлів без необхідності відкривати їх у сторонніх програмах.

7. Аналіз використання дискового простору:
Визначення найбільших файлів та папок для ефективного управління місцем на диску.

8. Журнал дій (Log):
Запис усіх операцій користувача (створення, видалення, переміщення файлів) у спеціальний журнал для контролю змін у файловій системі.
